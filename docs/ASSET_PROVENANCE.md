# Asset provenance

This record covers the visual assets shipped by PEAK1600. New assets must have a
documented origin before they are deployed.

## Project-created images

The following images were generated specifically for PEAK1600 with OpenAI image
generation on September 20, 2026. They were not downloaded from a photographer,
stock library, College Board, or another website, and they require no third-party
attribution for use in this project.

- `public/student-study.jpg`
- `public/math-study.jpg`
- `public/reading-study.jpg`
- `public/vocab-study.jpg`

The PEAK1600 summit mark is original vector artwork stored directly in the user
interface source.

## Excluded material

Official College Board artwork, screenshots, question content, and reference-sheet
images must not be shipped. Mathematical facts and formulas may be presented only
in PEAK1600's independently composed interface.
